What Nav2 is

Nav2 is the navigation stack for ROS 2. It takes a robot from its current pose to a goal pose while avoiding obstacles, using a map, sensor data such as laser scans, and the robot's odometry.

Main servers

  • BT Navigator runs a behavior tree that orchestrates the whole navigation task.
  • Planner Server computes a global path. Available planners include NavFn, the Smac Planner family, and Theta*.
  • Controller Server follows the path by producing velocity commands. Available controllers include DWB, Regulated Pure Pursuit, and MPPI.
  • Behavior Server runs recovery behaviors such as spin, back up, and wait when the robot gets stuck.
  • Smoother Server smooths planned paths.

Costmaps and localization

Nav2 uses a global costmap for planning and a local costmap for control. Costmaps are built from layers such as the static map layer, the obstacle layer, and the inflation layer. Localization against a known map is usually done with AMCL, and maps are served by the map server.

Lifecycle

Nav2 servers are ROS 2 lifecycle nodes. The lifecycle manager brings them up in order and can shut them down cleanly.
